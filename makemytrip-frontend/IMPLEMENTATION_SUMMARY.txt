┌─────────────────────────────────────────────────────────────────────────────┐
│ 📊 TECHNICAL ARCHITECTURE                                                   │
└─────────────────────────────────────────────────────────────────────────────┘

APP.jsx (Root)
    ↓
    ├─ useTheme() hook initialization
    │   └─ Load from localStorage
    │   └─ Apply to <html data-theme="...">
    │
    ├─ <ThemeSwitcher /> component
    │   └─ Dropdown UI with all 32 themes
    │   └─ On select → setTheme(name)
    │
    └─ Rest of app components
        └─ Use DaisyUI classes
        └─ Automatically update with theme

When user selects "dark" theme:
  1. setTheme('dark') called
  2. Validates theme name
  3. Updates <html data-theme="dark">
  4. DaisyUI CSS variables change
  5. All components using DaisyUI classes update colors
  6. Saves to localStorage
  7. Persists across sessions

┌─────────────────────────────────────────────────────────────────────────────┐
│ 💻 CODE EXAMPLES                                                            │
└─────────────────────────────────────────────────────────────────────────────┘

IMPORT HOOK:
  import { useTheme } from '../hooks/useTheme'

USE IN COMPONENT:
  const { theme, setTheme, themes } = useTheme()

GET CURRENT THEME:
  console.log(theme)  // → "dark"

CHANGE THEME:
  setTheme('cyberpunk')

GET ALL THEMES:
  console.log(themes)  // → ["light", "dark", ..., "sunset"]

USE IN JSX:
  <div className="bg-base-100 text-base-content">
    Current theme: {theme}
    <button onClick={() => setTheme('dark')}>Dark Mode</button>
  </div>

┌─────────────────────────────────────────────────────────────────────────────┐
│ 🎓 WHAT TO USE IN COMPONENTS                                               │
└─────────────────────────────────────────────────────────────────────────────┘

✅ USE THESE DAISYUI CLASSES:
  • bg-base-100, bg-base-200, bg-base-300
  • text-base-content
  • bg-primary, bg-secondary, bg-accent
  • btn btn-primary, btn btn-ghost
  • card bg-base-100 shadow
  • input input-bordered
  • alert alert-success
  • badge badge-primary

❌ DON'T USE THESE:
  • bg-blue-500, bg-red-400
  • text-green-600, text-yellow-300
  • style={{ backgroundColor: '#ffffff' }}
  • hardcoded hex colors like #1f6db8

WHY?
  ✓ DaisyUI classes automatically change with theme
  ✗ Hardcoded colors are stuck (don't change)
